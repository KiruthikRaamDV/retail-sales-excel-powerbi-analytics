# Power BI Desktop report

Upload `Retail_Sales_Analytics_500.pbix` here. It contains the report developed from the 500-transaction Excel dataset.

The report covers Executive Overview, Product Analysis, Sales Drivers, and Product Details.

**To open:** Install Power BI Desktop, open the `.pbix` file and, if needed, change its Excel source path to the downloaded workbook in `excel/`. See [the full walkthrough](../docs/HOW_TO_EXPLORE.md).
