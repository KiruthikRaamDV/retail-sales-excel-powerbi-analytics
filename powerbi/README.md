# Power BI report

[Download the completed Power BI report](Retail%20Sales%20Analytics%20500.pbix).

This report builds on the 500-transaction Excel workbook and includes four pages: Executive Overview, Product Analysis, Sales Drivers and Product Details.

I used Power Query for preparation and validation, a Date table for monthly analysis, and DAX measures for sales KPIs, month-over-month growth, revenue share, average units per order and product ranking. The Product Details page supports drill-through from the report.

**Opening the file:** Use Power BI Desktop. If refresh fails because the Excel workbook path belongs to another computer, change the data source to the downloaded [Excel workbook](../excel/Retail_Sales_Analytics_500_Transactions.xlsx) and refresh.
